## Analysis model

| Source | How |
| --- | --- |
| **Cursor agent** (primary) | `/analyze-retro` → `POST .../analysis/import` |
| **Baseline** (tests only) | `POST .../analysis/generate/baseline` |

No external LLM API keys in this service. AI analysis is performed by the Cursor agent in the parent orchestration repo.

JSON and Markdown under `data/retrospectives/{retroId}/`. Status lifecycle: `draft` → `open` → `closed` → `archived`.
